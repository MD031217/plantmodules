Зелёная полка - распределенная IoT-система для мониторинга микроклимата и автоматизации ухода за растениями
Проект представляет собой аппаратно-программный комплекс, построенный по архитектуре offline-first. Каждый узел системы обладает вычислительной автономностью, локальным хранением данных (SQLite3 на SD-карте) и встроенным веб-интерфейсом, что минимизирует зависимость от внешнего сетевого соединения.
Система состоит из двух независимых модулей на базе микроконтроллера ESP32-C3.

1. Модуль мониторинга климата.
Собирает данные о температуре, влажности воздуха, атмосферном давлении (BME280, SPI) и влажности почвы (аналоговый сенсор). Данные выводятся на E-Ink дисплей 1.54" с использованием режима частичного обновления (DisplayPartFrame) для экономии энергии.

Функционал веб-интерфейса и backend-логики:
- Встроенный HTTP-сервер (порт 80, WebServer.h).
- Аутентификация через 24-символьные Bearer-токены.
- Хранение данных в нормализованной SQLite3 базе на SD-карте (таблицы: SensorLog, Users, Sessions, Plants).
- Защита от SQL-инъекций: все запросы выполняются через подготовленные выражения (sqlite3_prepare_v2, sqlite3_bind_*).
- Загрузка файлов через multipart/form-data с валидацией MIME-типов (JPEG, PNG, WEBP) и размера. Пути к файлам сохраняются в БД.
- Обмен данными через REST API с использованием ArduinoJson (DynamicJsonDocument).
- Поддержка режимов Wi-Fi Station и Access Point. Provisioning через Preferences.h (NVS).
- Синхронизация времени по NTP, поддержка обновлений по воздуху (ArduinoOTA).

Клиентская часть (Embedded Frontend):
- Веб-ресурсы хранятся в сжатом виде в PROGMEM.
- Стек: Vanilla JavaScript (ES6+), HTML5, CSS3. Отказ от тяжелых фреймворков.
- Визуализация исторических данных реализована нативно через HTML5 Canvas API (масштабирование осей, тултипы) без использования внешних библиотек.
- Асинхронный обмен данными через Fetch API, хранение токенов и настроек темы в localStorage.

2. Модуль автополива.
Предназначен для управления до 8 клапанами полива. Будет использовать аналогичный стек технологий (ESP32-C3, SQLite3 на SD, встроенный веб-сервер).

Планируемый функционал:
- База данных из 6 таблиц: клапаны, задачи, операции внутри задач, очередь запусков, журнал поливов.
- Поддержка 5 типов расписаний: ежедневное, однократное, интервальное, еженедельное, по восходу/закату.
- Приоритизация задач, последовательности операций с повторениями, автоматический полив по расписанию с защитой от частого срабатывания.

Примечание: В текущей версии модули работают независимо. В будущем планируется синхронизация через HTTP API или MQTT.

Технологический стек:
Микроконтроллер - ESP32-C3 
Язык и среда - C++, Arduino Core 
База данных - SQLite3 (sqlite3.h) на SD-карте (FAT32)
Безопасность БД - Prepared statements (sqlite3_prepare_v2)
Сеть и сервер - WebServer.h (порт 80), mDNS, NTP, ArduinoOTA, Preferences.h (NVS)
Формат данных - JSON (ArduinoJson / DynamicJsonDocument)
Frontend - HTML5, CSS3 (CSS Variables), Vanilla JS (ES6+), Fetch API, Native Canvas API
Периферия - BME280 (SPI), Аналоговый датчик влажности (GPIO0), E-Ink 1.54" (SPI), MicroSD модуль (SPI)
